Code For Marriageの評判・料金｜エンジニア専門結婚相談所の特徴

最終更新: 2026年7月（料金は2026年7月に公式サイトで確認）

Code For Marriageの特徴と適している方

  • ●特徴：ITエンジニア専門×仲人が全員元SE×100%リモート対応を組み合わせた相談所です。IBJ正規加盟のため、出会いの母数は全国規模です。
  • ●料金：入会費77,000円＋月会費11,000円＋成婚費220,000円（税込）です。1年で成婚した場合の総額目安は約42.9万円。U-30プランなら若手はさらに割安です。
  • ●適している方：仕事や技術の話を詳しく説明しなくても理解してくれる担当者を求めるエンジニアの方、地方在住やリモート勤務で通所が難しい方に適しています。
  • ●注意点：2022年設立で第三者口コミが少ないため、無料相談での相性確認が判断の中心になります。

※本ページの料金等は公式サイトの公表情報（2026年8月17日確認・税込）にもとづきます。最新かつ正確な数値・契約条件は公式サイトおよび無料相談で必ずご確認ください。

Code For Marriageの強み・特徴

日本初を掲げるITエンジニア専門の結婚相談所

2022年設立で、対象をITエンジニア・IT職に特化しています。エンジニアの働き方（リモート・裁量労働・技術の話題）を前提にした婚活支援を掲げており、「趣味や仕事を理解してもらえない」という婚活のミスマッチを減らしやすい設計です。

仲人（カウンセラー）が全員元SE

公式サイトによれば、担当する仲人は全員がシステムエンジニア出身です。職務内容や繁忙期の事情を詳しく説明しなくても理解してもらえる点は、この相談所ならではの強みです。技術職特有の「自己PRの言語化」も相談しやすい環境といえます。

100%リモート対応で全国から利用できる

カウンセリングから活動サポートまでオンラインで完結します。所在地は東京ですが、地方在住のエンジニアやフルリモート勤務者でも利用可能です（お見合い自体はIBJの仕組みで対面・オンライン両方があります）。

IBJ正規加盟＋U-30向けの割安プラン

IBJ（日本結婚相談所連盟）の正規加盟店で、お相手探しは全国規模の会員ネットワークが対象です。30歳以下限定のU-30プラン（入会33,000円・月7,700円・毎月1名限定と公式明記）があり、若手エンジニアは初期負担を抑えて始められます。

口コミが少ない専門相談所の見極め方

当サイトの調査（2026年7月時点）では、Code For Marriageの第三者による口コミ・体験談はWeb上にほとんど存在しません。当サイトは実在しない口コミを作成・掲載しない方針のため、代わりにエンジニアが専門特化型の相談所を見極めるポイントを整理しています。

  • 1.「元SE」の経歴を無料相談で確認する：担当仲人の経歴（開発経験・業界）を聞き、自分の職種・働き方をどこまで理解して提案してくれるかを確認します。
  • 2.IBJ加盟という客観的事実を土台にする：出会いの母数はIBJネットワークに依存するため、相談所の規模より「サポートの質」で選ぶことが、専門特化型の相談所を評価する際の適切な基準です。
  • 3.リモート完結の相性を確かめる：無料相談自体がオンラインで行われるため、画面越しに本音を話せるかをその場で確認できます。
  • 4.契約条件を書面で確認する：中途退会時の精算・休会制度・成婚の定義（IBJ準拠か）は、必ず書面でご確認ください。

Code For Marriage（コードフォーマリッジ）のご利用の流れ（初めての方向け）

結婚相談所を初めて利用する方に向けて、無料相談から成婚退会までの標準的な流れを8つのステップでご説明します。 結婚相談所は、会員全員が身元確認を受けている、お断りの連絡を相談所が代行する、解約のルールが法律で定められているという点で、 婚活サービスの中でも仕組みとして安心して利用しやすい形態です。

  1. 1

    無料相談・資料請求

    入会前に、サービス内容・料金・「成婚」の定義（どの時点で成婚料が発生するか）を確認します。無料相談で入会を強制されることはなく、複数社の説明を聞いて比較してから決めるのが一般的です。

    ポイント：総額・成婚の定義・中途退会時の精算方法を確認します

  2. 2

    入会手続き（必要書類の提出）

    独身証明書・住民票・本人確認書類・収入証明（主に男性）・学歴証明（短大卒以上）などを提出します。全会員が書類を提出する仕組みのため、既婚者や身元の不明な方が入会しにくく、安心して利用しやすい環境です。

    ポイント：独身証明書は本籍地の市区町村役場で取得できます（郵送での請求も可能）

  3. 3

    プロフィール作成

    写真撮影とプロフィール文の作成を行います。お見合いの申込率にもっとも大きく影響するのは写真です。多くの相談所が、提携スタジオでの撮影や服装のアドバイスを用意しています。

    ポイント：写真はスマートフォンでの自撮りではなく、プロによる撮影が基本です

  4. 4

    お相手探し（検索・紹介）

    システムでの検索・申込と、カウンセラーからの紹介を並行して進めます。申込可能件数は、相談所・プランごとに定められています。

    ポイント：活動開始から1〜2ヶ月は、申込数を多めにすることをおすすめします（出会いの母数が結果に影響するためです）

  5. 5

    お見合い

    ホテルのラウンジなどで1時間程度お話しします（オンラインに対応する相談所も多くあります）。連絡先は直接交換せず、交際を希望するかどうかは相談所を通じて回答します。

    ポイント：その場で返事をする必要はなく、お断りの連絡も相談所が代行します

  6. 6

    仮交際（プレ交際）

    お互いをもう少し知りたいと感じた段階の交際です。結婚相談所では複数の方と並行して交際することがルールとして認められており、不誠実な行為にはあたりません。

    ポイント：判断に迷う場合はカウンセラーに相談できます（交際中の悩み相談もサポートの範囲です）

  7. 7

    真剣交際

    お相手を1人に絞り、結婚を前提に話し合いを深める期間です。ほかの方との交際・お見合いはすべて終了します。

    ポイント：結婚観・お金・家族について、具体的に話し合う時期です

  8. 8

    プロポーズ・成婚退会

    婚約の意思が固まると「成婚退会」となります。成婚料が設定されている相談所では、この時点で支払います。活動開始から成婚退会までの期間は、1年前後が1つの目安です。

    ポイント：成婚料の金額と発生条件は、入会前にご確認ください

初めて利用する方からのよくある質問

無料相談に行くと勧誘されませんか？

無料相談はサービスの説明を受ける場です。その場で契約する義務はありません。「他社と比較してから決めます」とお伝えいただいて問題なく、複数社の比較検討は一般的に行われています。

入会後に「合わない」と感じたらやめられますか？

退会できます。結婚相談所の契約は特定商取引法の特定継続的役務提供にあたり、契約書面の受領から8日以内であればクーリングオフ（無条件解約・全額返金）が、その後も中途解約が法律で認められています（精算方法は契約書に記載されます）。

仕事が忙しくても活動できますか？

オンライン面談・オンラインお見合いに対応する相談所が増えており、平日の夜や土日に活動する方が多数です。活動ペースについても、カウンセラーに相談できます。

費用はいつ・何に払いますか？

①入会時（初期費用）、②毎月（月会費）、③お見合い時（お見合い料。無料の相談所も多くあります）、④成婚退会時（成婚料）の4種類が基本です。月会費が安くても成婚料が高い場合があるため、総額で比較することをおすすめします。

よくある質問

Code For Marriageの料金は総額いくらかかりますか？+
公式公表の料金（税込・2026年8月17日確認）は、スタンダードプランで入会費77,000円＋月会費11,000円＋成婚費220,000円です。1年活動して成婚した場合の総額目安は約429,000円（77,000＋11,000×12＋220,000）です。30歳未満はU-30プラン（入会33,000円・月7,700円）でさらに抑えられます。最新の料金は公式サイトでご確認ください。
エンジニア以外でも入会できますか？+
サービスはITエンジニア・IT職向けに設計されています。エンジニア以外の方の入会可否は公式サイトに明記がないため、無料相談でご確認ください。「エンジニアと結婚したい」お相手探しはIBJネットワーク全体が対象になります。
地方在住でも利用できますか？+
利用できます。公式サイトは100%リモート対応を明記しており、カウンセリングやサポートはオンラインで完結します。お見合いはIBJの仕組み上、対面・オンラインの両方があります。
口コミがほとんど見つからない場合、どのように判断すればよいですか？+
2022年設立の小規模専門相談所のため、第三者の口コミはWeb上にほとんどありません（2026年7月時点の当サイト調査）。判断材料は、IBJ正規加盟という客観的事実、料金の透明性、無料相談での相性確認に置くことをおすすめします。当サイトは実在しない口コミを掲載しない方針のため、体験談の紹介はしていません。
IBJ加盟とはどういう意味ですか？+
IBJ（日本結婚相談所連盟）は全国の結婚相談所が加盟する連盟で、加盟相談所の会員同士がお見合いできます。Code For Marriageは会社概要等でIBJ正規加盟を明記しており、小規模でも出会いの母数は全国規模です。
他のエンジニア向け婚活サービスとの違いは何ですか？+
マッチングアプリと違い、独身証明書等の提出を前提とする結婚相談所の仕組み（IBJ）の上で、仲人が伴走する点が特徴です。その中でも「仲人が全員元SE」という専門特化は珍しく、職業への理解があるサポートを重視する方に適しています。
